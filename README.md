# Caminhos de Esperança

Um site que tem como missão promover a informação, a orientação e as redes de apoio às famílias que buscam pessoas desaparecidas em um contexto de possível tráfico humano, facilitando o acesso a procedimentos seguros, instituições competentes e recursos de assistência, independentemente de fronteiras geográficas.
